Effect dropdown with an attached panel (Aurora-kep2.2)

No Video/Audio toggle. An "Effects" label sits above the trigger like Monitor below it. The panel is non-modal (no scrim, closes on outside click or Esc), a labeled dialog holding an ARIA tree. Frame 9 is the working spec, frames 1-7 are static states of the same tree, and frame 8 is the rejected button-row alternative. Tooltips and row menus render in the panel outside the tree and its scroll region, under their row, flipped above it when they would leave the viewport. Built-in rows can only be duplicated or hidden. Hidden is a collapsed-by-default group with no count and only renders when non-empty. Every group header collapses. No row is dimmed: failures such as a missing input surface only after the click, through the inline switch error or the shell banner. The running effect has no Hide item. Rows carry no input badges. A secondary text line under the name is used only for "Built-in" on hidden built-ins.

Frame 1: built-in row menu

Fire selected. Built-in rows offer Duplicate and Hide. Hidden is collapsed at the bottom. The row menu sits in the panel outside the tree, under its row.

Frame 2: custom row menu, Hidden expanded

Unhide and Duplicate on a hidden row. The Hidden header is an expandable tree node (aria-expanded).

Frame 3: long list

The list scrolls inside the panel. Group headers stick within their section and the New effect footer stays pinned. The Lava lamp menu would run off the bottom, so it flips above its row. It lives outside the scroll region, so the list does not clip it.

Frame 4: groups collapsed

Every group header is an expandable tree node with the chevron on the left edge, lined up with New effect. A collapsed group that holds the selected effect shows a check at the right of its header (the trigger already names the effect).

Frame 5: description tooltip

Hovering or focusing a row shows its description (role=tooltip, linked by aria-describedby on the row). Like the row menu, it renders in the panel outside the tree and its scroll region. Touch has no hover, so the description is a supplement and nothing essential lives only in it.

Frame 6: both built-ins hidden

A group renders only when it holds a visible effect. With both built-ins hidden the Built-in header is gone and they sit under Hidden. Custom and Hidden follow the same rule.

Frame 6b: built-ins hidden and no custom effects

Only Hidden renders. Its rows can still be picked: a hidden effect may run and keeps its check inside Hidden. Only the running effect's menu drops Hide.

Frame 8: button rows (rejected, interactive)

Kept for the record: the tree in frame 9 was chosen. Same look as frame 1 with rows built as buttons (aria-current on the running effect) inside role=group. This frame works: Up/Down/Home/End move focus without switching, Enter, Space or click switches, Right and Left hop between a row and its ellipsis, Esc returns to the trigger, group headers collapse. The list is one tab stop. The trigger is named "Effects, Fire". The last action prints under the page and is announced through a live region.

Frame 9: tree (the spec, interactive)

The list is an ARIA tree: group headers are expandable nodes and effects are their children, all in one arrow sequence. Up/Down walk headers and rows. Right expands a group or steps into it, Left collapses it or steps out to its header. Enter or Space switches on a row and toggles on a header. Typing a letter jumps to a match. A treeitem cannot hold a button, so the ellipsis is mouse-only. On a row, Right opens its actions menu (like stepping into a group) and Left or Esc closes it. Shift+F10 and the Menu key do the same. The row announces that it has a menu. Hide and Unhide work and show where focus lands. The panel is one tab stop. New effect is the last item in the arrow sequence, so Down from the last row (or End) lands on it and Up returns.

Frame 7: closed

Also the success state of a switch: the label moves to the new effect only once the running pipeline confirms it, and the live region announces "Switched to Rainbow drift."

Switch states

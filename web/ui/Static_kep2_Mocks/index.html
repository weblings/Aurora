Effect dropdown with an attached panel (Aurora-kep2.2)

No Video/Audio toggle. An "Effects" label sits above the trigger like Monitor below it. The panel is non-modal (no scrim, closes on outside click or Esc), a labeled dialog holding radios and buttons. Built-in rows can only be duplicated or hidden. Hidden is a collapsed-by-default group with no count and only renders when non-empty. Every group header collapses. A gated effect stays clickable (aria-disabled), dimmed, with no reason line: the shell banner explains after the click. The per-row reason line stays in the markup, dormant.

Frame 1: built-in row menu

Fire selected. Built-in rows offer Duplicate and Hide. Hidden is collapsed at the bottom. In the real panel the row menu must render outside the scroll region so it is not clipped.

Frame 2: custom row menu, Hidden expanded

Unhide and Duplicate on a hidden row. The Hidden header is a disclosure button (aria-expanded).

Frame 3: long list

The list scrolls inside the panel. Group headers stick within their section and the New effect footer stays pinned.

Frame 4: groups collapsed

Every group header is a disclosure button with the chevron on the left edge, lined up with New effect. A collapsed group that holds the selected effect shows a check on the header (the trigger already names the effect). Two placements to compare.

Frame 5: description tooltip

Hovering or focusing a row shows its description (role=tooltip, linked by aria-describedby on the radio). Touch has no hover, so the description is a supplement and nothing essential lives only in it. Like the row menu, it must render outside the scroll region.

Frame 6: both built-ins hidden

A group renders only when it holds a visible effect. With both built-ins hidden the Built-in header is gone and they sit under Hidden. Custom and Hidden follow the same rule.

Frame 6b: built-ins hidden and no custom effects

Only Hidden renders. Nothing is visible to select, which conflicts with the rule that the selected effect cannot be hidden. See the open question.

Frame 8: button rows instead of radios (interactive)

Same look as frame 1 with rows built as buttons (aria-current on the running effect) inside role=group. This frame works: Up/Down/Home/End move focus without switching, Enter, Space or click switches, Right and Left hop between a row and its ellipsis, Esc returns to the trigger, group headers collapse. The list is one tab stop. The trigger is named "Effects, Fire". The gated Candle row explains instead of switching. The last action prints under the page and is announced through a live region.

Frame 9: tree (interactive)

The list is an ARIA tree: group headers are expandable nodes and effects are their children, all in one arrow sequence. Up/Down walk headers and rows. Right expands a group or steps into it, Left collapses it or steps out to its header. Enter or Space switches on a row and toggles on a header. Typing a letter jumps to a match. A treeitem cannot hold a button, so the ellipsis is mouse-only. On a row, Right opens its actions menu (like stepping into a group) and Left or Esc closes it. Shift+F10 and the Menu key do the same. The row announces that it has a menu. Hide and Unhide work and show where focus lands. The panel is two tab stops: the tree, then New effect.

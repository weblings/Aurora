Effect dropdown with an attached panel (Aurora-kep2.2)

No Video/Audio toggle. The trigger looks like today's dropdown. The panel drops from the trigger and is non-modal (no scrim, closes on outside click or Esc). It is a labeled dialog in ARIA terms: rows are visually hidden radios (a check mark shows the selection) with a separate ellipsis button. Input icons: monitor = video, speaker = audio. Sample effects: Screen colors (video), Music pulse (audio), Fire (audio, selected), Candle (video, gated), Rainbow drift (both).

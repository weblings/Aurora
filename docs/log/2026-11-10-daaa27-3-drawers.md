# Graph editor: Details and Dashboard controls drawers, on-node mark

Id: daaa27-3-drawers

`Aurora-daaa.27.3`. Part of stage 4 ([[daaa27-2-delete-key]], [[daaa28-grille-drawer]]).

- `DetailsDrawer`: title, purpose, ports, Show on the Dashboard checkboxes; under each ticked one, Label, Section and Tooltip (shared `CommitInput`). Follows the selection once open; selecting does not open it.
- `ControlsDrawer`: order, remove, review; opened from a canvas button, "Dashboard controls (N)".
- One drawer at a time (`drawer` state in `App.tsx`), non-modal, canvas clicks leave it open. Node menu Details opens Details; Show on the Dashboard opens it with focus on the first checkbox.
- On-node mark: `dashboardParams` in node data from `controlsOf`; `ParamWidget` shows a `◆` with visually hidden text, not a tab stop.
- The Inspector stays until `Aurora-daaa.27.4`; both show the same data meanwhile.
- **Surprise 1:** Backspace with focus on the drawer container deleted the selected node (React Flow's delete key skips only inputs). `deleteKeyCode` is `null` while focus is in a drawer.
- **Surprise 2:** Grille's Drawer closes on Esc only with focus inside, so after a canvas click Esc did nothing. App-level window handler added, yielding to menus and popups. Upstream design question filed as `Aurora-daaa.27.5`.

## Verification

- `tsc`, build and Vitest (121) pass. Browser run (Playwright on cached Chromium, Vite dev server proxied to the `--input dummy` light stack): marks match the 3 controls and go to 4 on a tick; controls drawer stays open on a canvas click; Details follows selection; Backspace in the drawer keeps all 8 nodes; ticking adds the three fields; opening the controls drawer replaces Details; Esc closes after a canvas click; with a menu open the first Esc closes only the menu; Show on the Dashboard focuses the first checkbox.
- Not checked: a screen reader on the on-node mark; keyboard-only reorder in the controls drawer; narrow windows; the checks are not committed as a browser suite (`Aurora-daaa.27.4` covers coverage).
- Built-in controls have no label, so the controls drawer shows "No label"; falling back to the param name is open.

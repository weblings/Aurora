Id: daaa11-top-bar

- Save stays in the title menu (the `daaa.5` decision), not on the bar as the bead text says. The menu now also holds Name, New empty effect and the other effects. Effects open on a click or Enter, never on arrow keys.
- `graph/status.ts` implements the priority rule and is unit-tested for every rank. Test outcomes and write failures show until the next test, Save or edit; `Reverted`, `Saved`, `Restored`, `Discarded`, `Added` and a refused wire are toasts.
- `Whole graph` problems and node problems share one chip. The `Add node...` action only focuses the first palette item until the Add node menu exists (stage 3).
- Found on the way: Grille's `tokens.css` was never imported, so every popup since `daaa.10` drew with no background. It is imported now.
- Checks migrated off `.editor-header select`, `.editor-name input`, `.editor-test-note` and `.editor-notice`; helpers in `tools/browser-check/lib/editorMenu.mjs`. New `graph-editor-top-bar.mjs`.

# Graph editor stage 6f: a failed Save is a shell row, the banner is gone, the priority rule is rewritten

Id: u68h7-close-out

`Aurora-u68h.7` (stage 6f) and the epic `Aurora-u68h`. No core, server or Grille change (Grille stays on `0.1.0-dev.12`).

## Failed-save row (owner decision, 2026-11-13)

- **What.** A Save, Save as new or Save and apply that Aurora refused or could not write (the last use of `writeTrouble` and `.editor-banner`) is an editor-supplied error-shell row, same markup and `notes` path as the draft and open-failure rows. No Retry, no action, no dismiss.
- **Wording.** `graph/hostState.ts` `failedSaveNote(title, reason)`: `Couldn't save <title>: <Aurora's reason>`. The reason is the server's own words from `api.ts` `refusal`. `<title>` is the title of the graph being written (`titleOf(sent)`, so Save as new from a built-in names the new title), else the title button's label (`barTitle()`: the effects-list title, else the id, `New effect` for a not-yet-saved effect), the fallback 6h uses.
- **Clearing.** The next Save (`write` clears it first) or any edit of the document. Starting a test no longer clears it (the old banner did).
- **Network failure.** `writeFailureReason(e)` is null for fetch's `TypeError`: no row, the "Aurora has stopped" takeover says it (the host poll owns that verdict). A refused draft PUT inside a write (`DraftRefused`, which carries the server's `code`) and any other error get a row: `too many editors are open` for `too_many_drafts`, `Aurora would not take the draft` for other codes, the error's message otherwise (`Aurora did not answer` if empty).
- **Problems refusals** stay 6d's chip callout; nothing is written and no row appears.
- **Status.** The row is not a Test state. `pickStatus` loses its `writeTrouble` input and rank 6; ranks are now 1, 4, 5, 7 (`StatusRank`), and `Status.where` is `'button' | 'none'`. Test is not disabled by a failed Save.

## Banner removal

`pickBanner`, the `Banner` type, the `.editor-banner` CSS, the banner JSX and the `where: 'banner'` case are deleted, with their unit tests. `grep -rn "editor-banner\|pickBanner" web/graph-editor tools/browser-check` finds nothing. The old `.editor-banner` count-is-zero assertions in seven checks went with the class (they could not fail any more).

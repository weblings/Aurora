# WASM build and parity job in CI

Id: 51nv7-wasm-ci

`Aurora-51nv.7` (A5). This adds the WASM build and parity job, `.github/workflows/wasm.yml`. Background: [[51nv6-browser-engine]].

- **Pins.** `core/Wasm/versions.env` pins emsdk 7.0.0, the OpenCV 4.12.0 tarball and the aubio commit vcpkg's port pins, each with a SHA256.
- **`core/Wasm/build-deps.sh`.** Builds OpenCV core and imgproc for WASM and natively with the spike's flags, and fetches aubio. It skips an install that already exists.
- **`AURORA_AUBIO_FROM_SOURCE`.** Now a core option (`Wasm/AubioFromSource.cmake`), ON under Emscripten and OFF natively. When it is OFF, AudioProcessing's existing lookups are unchanged.
- **Native graph-only configure.** `AURORA_CORE_GRAPH_ONLY` now works on a native compiler and builds `graph_parity` and `GenServerSamples` from the same sources as the WASM build.
- **Seeded parity case.** `parity/main.cpp` gained `audio-seeded`. The built-in audio graph has no `palette.randomAnchor`, so this mode swaps one in (seed 7) and leaves the hue unset, covering seeded picks (`Aurora-kuee`).
- **`compare.py`.** Passes when every channel differs by under 1/255. It reports bit-identical and 8-bit-difference counts and appends a line to the job summary.
- **`wasm.yml`.**
  - Clones emsdk and uses only `actions/*`.
  - Caches emsdk and both OpenCV installs.
  - Runs three parity cases, the engine Node test and the sample `--check`.
  - Uploads `aurora-engine-wasm` (module, `.wasm`, `build-info.json`) for 7 days, with the gzip size in the summary.
  - Runs on pull requests and pushes to main, and is callable from the Pages deploy (`workflow_call`).

## Verification
- **Windows, native.** MSVC with vcpkg OpenCV and the pinned aubio from source, against WASM built with the pinned OpenCV. Video, audio and audio-seeded are all bit-identical. Native output from aubio-from-source matches the vcpkg aubio output byte for byte.
- **Windows, other checks.** `build-deps.sh wasm` from the pinned tarball took 6 min. The core-tests build and ctest pass, 513 of 513. windows-app builds. `engine.test.mjs` passes 13 of 13. `wasm.yml` parses.
- **Never run before CI.** The workflow itself, the native OpenCV and aubio builds on gcc, glibc against Emscripten parity, the caches, the artifact upload and `workflow_call`.

# Graph editor pins Grille 0.2.2 from npm

Id: aiy2-grille-0-2-2-npm

`Aurora-aiy2`, closed. Replaces the `v0.2.2-dev.5` GitHub tarball pin from [[7p8f-notice-chat-icon]], which npm 12 refuses.

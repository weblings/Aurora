# math.step node

Id: h87j-math-step

`Aurora-h87j`. `math.step` is a stateful Float to Float node in `MathNodes.cpp`. It outputs 1 at or above `edge` and 0 below, and after a flip up it flips back only below `edge - hysteresis`. `invert` swaps the outputs, a wired `edge` wins over the param. The output stays Float as in GLSL step, so a later Bool type never retypes it. A negative `hysteresis` fails the node at evaluate like `math.clamp`, because the loader clamps params to the declared min and a min of 0 would hide it (so the catalog shows -1e6). The loudness switch recipe in [[node-conversion-gaps]] now uses it. Catalog sample and `validate-errors.json` regenerated with `GenServerSamples`.

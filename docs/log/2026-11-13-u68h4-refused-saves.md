# Graph editor stage 6d: refused saves point at the problems chip, unsaved dots

Id: u68h4-refused-saves

`Aurora-u68h.4` (stage 6d, epic `Aurora-u68h`) with `Aurora-u68h.8` folded in. Built to the bead's rewritten description (2026-11-12) and the owner's 2026-11-13 note. No core or server change. Grille moves from `0.1.0-dev.11` to `0.1.0-dev.12` (`dotIcon`; MenuItem and SubmenuItem `tooltip` and `tooltipOnlyWhenTruncated`; MenuItem `description` no longer sets `title=`). The bump broke nothing: typecheck, tests and every check passed on it unchanged.

- **Refused saves.** Save, Save as new and Save and apply are never disabled. `App.write` checks `problemCount(problems)` first (the chip's own count: node, port and param messages, Whole graph rows, `Draft would not load`, `draft_too_large`), before the naming dialog and before any request. With problems it writes nothing, the menu closes, and `ProblemsChip` gets a `Refusal`. The server's own verdict on the sent draft (a stale chip) takes the same path with its error count. The callout replaced `Fix the N problems before saving` in the status spot (no longer produced; `pickBanner` and `.editor-banner` stay for 6f). Test's disabled reason now also counts `draftIssues` (a draft that would not load), not only `valid === false`.
- **Callout and ping.** The chip focuses itself, shows a `role="status"` callout on its left (a `ui-tooltip`-look element, dashed `--aurora-text-primary` border like `.aurora-node-problem`, a pointer toward the chip), and `PING_BEAT_MS` 1450 later gains `data-pinging`: a `::after` dashed border with two box-shadow pulses (1375 ms each) that ends when the callout closes at `CALLOUT_MS` 4200. Escape closes the callout early. Reduced motion keeps the border and drops the pulse. The popover stays closed. Grille's `Tooltip` could not host it: it is hover/focus-driven with `role=tooltip`, and its trigger type has no controlled `isOpen`. The live region wrapper is always mounted so the text is read when it appears.
- **Focus.** `EditorPopup` takes `focusAfter`, a ref App sets to a function returning the element focus should land on; the popup's restore (an effect when it closes, in Grille's `Popover`) reads it, so the choice wins over the restore to the trigger. A refused Save sets it to the chip; a problems row sets it to the node's `.react-flow__node[data-id]` (`focus({ preventScroll: true })`, so React Flow's pane is not scrolled). The ring shows after keyboard use only (the browser's `:focus-visible`, which the check reads for mouse and keyboard). Enter or a click on the chip focuses the first problem row.
- **Unsaved dots, all `<Icon icon={dotIcon} size="sm" />`.** Title: after the name at every width, the button's accessible name becomes `Effect menu, unsaved changes`; the word `Unsaved` and `.editor-dirty-mark` are gone. Open ▸: `graph/autosave.ts` `keptCopies()` lists the kept copies; `openGroups` builds Not saved yet (the `@new-*` copies, titled from their graph, else `New empty effect`), Custom, Built-in. A Custom or Built-in item with a kept copy gets the dot and MenuItem `description` `unsaved changes`; Not saved yet items get none and their heading ends with the dot and hidden text `, unsaved changes`. No counts in the menu. Opening an effect restores its copy silently (6b, unchanged).
- **Open ▸ long titles.** `Hint` and `LONG_TITLE` replaced by MenuItem `tooltip` and `tooltipOnlyWhenTruncated` (the title span keeps the 30ch ellipsis).
- **Grille type gap.** `MenuSection`'s `title` is typed `string` but drawn as the `Header`'s children, so the heading passes a node through a cast (`TitleMenu.tsx` `headingOf`). Worth typing as `ReactNode` in Grille.
- **Checks.** New `graph-editor:refused-save`: all three actions by mouse and keyboard (callout text, callout before ping with timings, popover closed, no naming dialog, focus on the chip with the ring only after keyboard, no request, no new effect, saved graph untouched), reduced motion, Enter on the chip to the first row, row to node focus by keyboard (ring) and mouse (no ring), title dot and name, Open dots and heading, silent restore. `top-bar` reads `data-unsaved` instead of the word. Unit: `titleMenu.test.ts`.
